# AI Assistant (Gemini Chatbot)

A simple Gemini-powered chatbot built as a first-year B.Tech CSE (AI & Data Science) project at Lovely Professional University.

## What it does
- Takes a question from the user
- Sends it to a Gemini model
- Shows the reply in a chat window

## Built with
- Google AI Studio (Build mode)
- Gemini API
- React, TypeScript and Vite
- Node.js server
- Firebase Firestore

## How to run
1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env` and add your own Gemini API key
3. Start the app: `npm run dev`
